# 팜맵 연동 가이드

> 확인 기준일: 2026-09-01  
> 대상 서비스: 농림축산식품부·농림수산식품교육문화정보원의 [농식품 팜맵 서비스](https://agis.epis.or.kr/ASD/main/intro.do)

## 1. 결론과 적용 범위

팜맵은 실제 농경지 구획을 표현하는 공간 기준도로서 다음 용도에 적합하다.

- 조사 대상 농경지 경계와 팜맵 고유번호 관리
- 항공사진·지적·행정자료의 공간 중첩
- 휴경, 시설 설치, 경계 변화, 지적 불일치 등 심층조사 후보 선별
- 조사원용 지도, 다필지 선택, 현장 결과의 공간 기록
- 연도별 면적·분류·변경 이력 비교

다만 팜맵만으로 농지 소유 적법성, 실제 경작자, 불법 임대차, 무단 휴경 또는 불법 전용을 확정해서는 안 된다. 농림축산식품부의 [농지 전수조사 시행지침](https://mafra.go.kr/bbs/home/795/597611/download.do)은 토지대장·등기, 농지대장, 농업경영체, 직불금, 전용허가 이력 등의 교차 확인과 심층 대상에 대한 현장조사를 요구한다. 따라서 이 시스템의 자동 분석 결과는 **의심·선별 정보**이며, 행정처분 근거가 되는 최종 판정은 권한 있는 담당자의 자료 검토, 현장 확인, 소명 및 결재를 거쳐야 한다.

권장 우선순위는 다음과 같다.

1. 공공데이터포털의 광역시도별 SHP를 내부 공간 DB에 버전 적재한다.
2. 공공데이터포털의 팜맵 조회 OpenAPI를 소량·보조 조회에 사용한다.
3. 팜맵 WMS는 화면 오버레이와 육안 대조에 사용한다.
4. 팜맵 웹 화면, 비공개 내부 API 또는 지도 타일을 크롤링하지 않는다.

## 2. 공식 데이터 소스

### 2.1 광역시도별 팜맵 SHP

[팜맵 공식 FAQ](https://agis.epis.or.kr/ASD/guide/faq.do?bbsSn=2)는 공공데이터포털에서 광역시도별 SHP를 내려받을 수 있다고 안내한다. 예시는 다음과 같다.

- [전라남도 팜맵 공간정보](https://www.data.go.kr/data/15104487/fileData.do)
- [서울·세종·6대 광역시 팜맵 공간정보](https://www.data.go.kr/data/15104481/fileData.do)
- [강원특별자치도 팜맵 공간정보](https://www.data.go.kr/data/15104490/fileData.do)
- [농림수산식품교육문화정보원 데이터 목록](https://www.data.go.kr/tcs/dss/selectDataSetList.do?conditionType=search&dType=&keyword=&org=%EB%86%8D%EB%A6%BC%EC%88%98%EC%82%B0%EC%8B%9D%ED%92%88%EA%B5%90%EC%9C%A1%EB%AC%B8%ED%99%94%EC%A0%95%EB%B3%B4%EC%9B%90&orgFilter=%EB%86%8D%EB%A6%BC%EC%88%98%EC%82%B0%EC%8B%9D%ED%92%88%EA%B5%90%EC%9C%A1%EB%AC%B8%ED%99%94%EC%A0%95%EB%B3%B4%EC%9B%90&orgFullName=%EB%86%8D%EB%A6%BC%EC%88%98%EC%82%B0%EC%8B%9D%ED%92%88%EA%B5%90%EC%9C%A1%EB%AC%B8%ED%99%94%EC%A0%95%EB%B3%B4%EC%9B%90)

SHP는 전국 일괄 파일이 아니라 지역별 데이터셋으로 제공되며, 최신 연도와 등록 시점이 지역마다 다를 수 있다. 파일명에 표시된 기준일, 수정일, 차기 등록 예정일 및 개별 라이선스를 수집 시마다 기록해야 한다. 공식 FAQ는 전국 팜맵이 연 1회 갱신된다고 설명하지만, 특정 지역 파일이 항상 같은 날 공개된다는 의미는 아니다.

SHP를 주 데이터로 권장하는 이유는 다음과 같다.

- 조사 대상 전체를 한 번에 공간 DB에 적재할 수 있다.
- 외부 API 장애와 호출량 제한 없이 공간검색·중첩·통계가 가능하다.
- 원본 스냅샷과 조사 시점의 데이터 버전을 재현할 수 있다.
- WMS 이미지와 달리 실제 벡터 도형을 분석할 수 있다.

### 2.2 공공데이터포털 팜맵 조회 OpenAPI

[농림수산식품교육문화정보원 팜 맵 조회 서비스](https://www.data.go.kr/data/15057368/openapi.do)는 REST 형식의 JSON/XML API다.

알려진 서비스 URL과 기능은 다음과 같다.

```text
서비스 URL
https://apis.data.go.kr/B552895/getFarmmapService

반경 기반 팜맵 상세조회
GET https://apis.data.go.kr/B552895/getFarmmapService/getAreaBasedFarmmapInfo
```

주요 요청값:

| 이름 | 의미 | 비고 |
|---|---|---|
| `serviceKey` | 공공데이터포털 인증키 | URL 인코딩 상태를 중복 인코딩하지 않도록 주의 |
| `numOfRows` | 페이지당 결과 수 | 페이지네이션 필수 |
| `pageNo` | 페이지 번호 | 1부터 시작 |
| `type` | `json` 또는 `xml` | 서버 내부에서는 JSON 권장 |
| `positionX`, `positionY` | 기준 좌표 | 팜맵 원 좌표계 기준 |
| `radius` | 반경(m) | 공식 명세상 최대 1km |
| `intpCode` | 판독코드 | 선택값 |
| `pnwlHistory` | 갱신이력코드 | 선택값 |
| `changeCode` | 변경구분코드 | 선택값 |

응답에는 팜맵 고유번호, 영상촬영년도, PNU 지번코드, 법정읍면동 코드·명칭, 지번, 판독코드·명칭, 판독영상 구분, 판독 입력일, 변경·갱신 이력, 도엽번호 등이 포함된다. OpenAPI는 화면 클릭이나 단건 보완 조회에는 유용하지만 전국 동기화를 반복 호출로 구현하기보다는 SHP를 배치 적재해야 한다.

공공데이터포털 페이지 기준 개발계정은 자동승인 및 10,000건의 신청 가능 트래픽이 제공된다. 운영계정은 활용사례를 등록해 증설을 신청할 수 있다. 실제 일·초당 제한과 승인 상태는 발급된 프로젝트의 콘솔 및 최신 명세를 기준으로 한다.

### 2.3 팜맵 자체 OpenAPI와 WMS

[팜맵 서비스 이용안내](https://agis.epis.or.kr/ASD/guide/faq.do?bbsSn=3)는 팜맵 자체 OpenAPI가 지도 API와 데이터 API를 제공하며, 회원가입과 팜맵 인증키 발급이 필요하다고 안내한다. 키 발급 시 활용 분야, 서비스 유형, 서비스명, 운영 상태, 사용할 도메인과 서비스 설명을 등록하며 계정당 최대 3개까지 발급할 수 있다.

공식 FAQ에 공개된 WMS GetCapabilities 예시는 다음과 같다.

```text
WMS 엔드포인트
https://agis.epis.or.kr/ASD/farmmapApi/wms.do

GetCapabilities
https://agis.epis.or.kr/ASD/farmmapApi/wms.do?service=wms&request=getCapabilities&apiKey={FARMMAP_API_KEY}&domain={REGISTERED_DOMAIN}

공식 FAQ에 표시된 레이어명
farm_map_api
```

근거: [QGIS 및 WMS/WFS 안내가 포함된 팜맵 FAQ](https://agis.epis.or.kr/ASD/guide/faq.do?bbsSn=2)

운영 시에는 발급받은 키로 GetCapabilities를 먼저 호출하고 다음 항목을 실제 응답에서 확인해야 한다.

- WMS 버전
- 정확한 레이어명과 사용 가능 연도
- 지원 좌표계와 이미지 형식
- 최대 이미지 크기 및 GetFeatureInfo 지원 여부
- 호출량·캐시 관련 최신 공지

팜맵 FAQ는 WMS/WFS로 외부 시스템에 팜맵을 오버레이할 수 있다고 설명하고 WMS의 구체 URL까지 제시한다. 그러나 같은 사이트의 다른 이용안내에는 여전히 “WMS/WFS 추후 추가”라는 오래된 문구가 남아 있다. 따라서 WMS는 GetCapabilities로 검증한 뒤 사용하고, **WFS는 엔드포인트·레이어·허용량을 최신 공식 명세 또는 운영기관 답변으로 확인하기 전까지 운영 의존성을 만들지 않는다.**

### 2.4 선택적 보조 API

다음 API는 영농환경 설명이나 현장조사 보조정보로 사용할 수 있으나 농지법 위반을 판정하는 직접 증거는 아니다.

- [팜맵 기반 토양검정 조회 서비스](https://www.data.go.kr/data/15058655/openapi.do)
- [팜맵 기반 병해충발생 조회 서비스](https://www.data.go.kr/data/15056670/openapi.do)
- [팜맵 기반 농업기상 조회 서비스](https://www.data.go.kr/data/15058627/openapi.do)

각 데이터셋의 활용신청, 트래픽, 갱신주기와 라이선스가 서로 다르므로 팜맵 SHP의 허락 범위를 그대로 적용해서는 안 된다.

## 3. 좌표계와 공간 처리

[팜맵 공식 FAQ](https://agis.epis.or.kr/ASD/guide/faq.do?bbsSn=2)에 따르면 팜맵의 원 좌표계는 **UTM-K (GRS80), EPSG:5179**다.

```text
+proj=tmerc +lat_0=38 +lon_0=127.5 +k=0.9996
+x_0=1000000 +y_0=2000000 +ellps=GRS80 +units=m +no_defs
```

운영 원칙:

1. 원본 SHP 도형은 EPSG:5179로 보존한다.
2. 면적·거리·중첩률 계산도 미터 단위 투영좌표계인 EPSG:5179에서 수행한다.
3. 웹 지도 전달 시에만 EPSG:4326 GeoJSON 또는 EPSG:3857 타일로 변환한다.
4. WMS가 EPSG:3857을 지원한다고 가정하지 말고 GetCapabilities 결과를 따른다.
5. 변환 전후 도형 유효성, 축 순서, 중심점 및 면적 오차를 표본 검증한다.

PostGIS 적재 예시에서는 원본 컬럼을 `geometry(..., 5179)`로 유지하고, 화면 전송 쿼리에서 `ST_Transform(geom, 4326)`을 적용하는 구성이 안전하다.

## 4. PNU 및 데이터 품질 한계

### 4.1 PNU는 팜맵의 절대 식별자가 아니다

[팜맵 FAQ](https://agis.epis.or.kr/ASD/guide/faq.do?bbsSn=2)는 팜맵과 지적 데이터가 100% 일치하지 않으며, 팜맵 PNU는 해당 농경지와 **가장 많이 중첩되는 지적의 PNU**라고 명시한다. 실제 지적공부의 PNU와 다를 수 있다. 팜맵의 주소·지역경계·지역코드는 법정동 기준이다.

따라서 다음 규칙을 적용한다.

- 팜맵 레코드의 기본 식별자는 `팜맵 고유번호 + 데이터 기준연도`로 둔다.
- PNU를 단독 기본키 또는 무조건적인 1:1 조인키로 사용하지 않는다.
- 팜맵과 지적의 관계를 별도 테이블로 관리하고 교차면적·중첩률을 저장한다.
- 한 팜맵이 여러 지적과 겹치거나 한 지적이 여러 팜맵으로 나뉘는 관계를 허용한다.
- PNU 불일치, 낮은 중첩률, 무효 도형, 중복 고유번호는 검토 큐로 보낸다.
- 행정처분 전에 최신 토지대장·등기 및 원 지적도와 다시 대조한다.

권장 관계 예시:

```text
farmmap_feature(snapshot_year, farmmap_id, geom, interpretation_code, ...)
cadastral_parcel(pnu, geom, cadastral_year, ...)
farmmap_cadastral_link(snapshot_year, farmmap_id, pnu,
                       intersection_area_m2, farmmap_overlap_ratio,
                       cadastral_overlap_ratio, match_status)
```

### 4.2 팜맵 연도와 항공사진 연도는 다를 수 있다

팜맵 화면은 팜맵 데이터 생성연도와 그 데이터 판독에 사용한 항공사진 연도를 구분한다. 데이터 갱신 지연, 지역별 영상 촬영 시점 및 외부 영상 서비스 상태를 고려해 두 연도를 별도 컬럼으로 보존해야 한다.

### 4.3 법적 효력이 없는 참고정보다

[팜맵 메인 화면](https://agis.epis.or.kr/ASD/main/intro.do)은 “본 시스템에서 제공하는 정보는 법적인 효력이 없으며, 참고용으로만 활용”하라고 명시한다. UI와 데이터 모델에서도 다음 상태를 구분한다.

```text
자동 선별 → 조사 배정 → 현장 확인 → 담당자 검토 → 소명/재조사 → 승인
```

자동 선별 결과를 `위반 확정`으로 표현하지 않고 `의심`, `확인 필요`, `자료 불일치` 등으로 표시한다. 판단 근거의 원본 버전, 조회 일시, 규칙 버전, 조사 증거 및 승인자를 감사로그에 남긴다.

## 5. 라이선스·저작권·자동화 유의사항

### 5.1 데이터셋별 라이선스가 우선한다

공공데이터포털의 [공공데이터 이용정책](https://www.data.go.kr/ugs/selectPortalPolicyView.do)은 데이터별 공공누리 유형과 제3자 권리를 확인하도록 안내한다.

- 위에 예시한 최신 지역별 팜맵 SHP와 팜맵 조회 OpenAPI 페이지에는 `이용허락범위 제한 없음`이 표시되어 있다.
- 토양·병해충·농업기상 API에는 공공누리 제1유형 출처표시 및 제3자 권리 표시가 붙어 있다.
- 동일한 이름의 과거 데이터나 다른 지역 데이터에 항상 같은 라이선스가 적용된다고 가정하지 않는다.
- 데이터 파일과 함께 출처 URL, 제공기관, 데이터명, 기준일, 다운로드일, 체크섬, 라이선스 문구를 보관한다.

화면이나 보고서의 권장 출처 표기는 다음과 같다.

```text
출처: 농림축산식품부·농림수산식품교육문화정보원 농식품 팜맵,
공공데이터포털, 데이터 기준연도 YYYY
```

### 5.2 팜맵 웹사이트를 크롤링하지 않는다

[팜맵 약관이 게시된 메인 페이지](https://agis.epis.or.kr/ASD/main/intro.do)는 농정원 작성 저작물의 권리를 농정원에 귀속시키고, 사전 승낙 없는 영리 목적 복제·송신·출판·배포 및 제3자 이용을 제한한다. 검색 자료의 복제·개조·번역 제공, 서비스 안정성을 해치는 행위도 이용제한 사유다. 서비스의 대량 이용이나 컴퓨터 간 연계가 특별한 경우 별도 계약으로 제공할 수 있다는 조항도 있다.

이에 따라 다음 행위를 금지한다.

- 로그인 세션을 자동화해 검색 결과를 대량 수집
- 브라우저 개발자 도구로 발견한 비공개 JSON 엔드포인트를 직접 호출
- WMS/항공영상 타일을 무단으로 대량 저장 또는 재배포
- 계정·인증키를 여러 기관이나 제3자와 공유
- 사이트 호출 제한을 회피하기 위한 키·IP 순환

대신 공개 SHP, 승인된 OpenAPI, 발급받은 WMS 키와 공식 다운로드 경로만 사용한다. 대량 이용, 외부 고객 대상 서비스, 상업 이용 또는 WFS 사용은 운영기관에 서면 확인한다.

### 5.3 외부 배경지도 권리는 별도다

팜맵 FAQ에 따르면 LX맵은 한국국토정보공사, 항공영상은 국토지리정보원 바로e맵 API 등 타 기관 자료를 사용한다. 팜맵 SHP의 라이선스가 이 배경지도나 항공영상 원본의 저장·가공·재배포까지 허용하는 것은 아니다. 화면 오버레이 이상의 이용은 각 원 제공기관 약관을 별도로 확인한다.

## 6. 권장 운영 연동 구성

```text
공공데이터포털 지역별 SHP
          │ 연간/수시 확인, 원본·체크섬·라이선스 보존
          ▼
   검증·정규화 배치 ── 스키마/CRS/도형/PNU 품질검사
          │
          ▼
      PostGIS 공간 DB ◀──── 보호된 행정자료 연계 영역
          │                  (농지대장·등기·경영체·직불·전용허가 등)
          ├── 위험선별/조사대상 생성
          ├── 내부 API(GeoJSON 또는 벡터타일)
          └── 버전·판정근거·감사로그
                    │
                    ▼
             웹/모바일 조사 화면
             ├── 내부 벡터 도형
             ├── 팜맵 WMS 육안 대조
             ├── 현장 사진/GPS/체크리스트
             └── 검토·소명·승인 워크플로

공공데이터 OpenAPI ── 서버측 캐시/백오프를 거친 보조 단건 조회
```

### 6.1 배치 적재

1. 지역별 최신 데이터셋의 메타데이터와 라이선스를 확인한다.
2. 공식 파일을 원본 그대로 보존하고 SHA-256 체크섬을 생성한다.
3. 파일명 인코딩, 필수 구성파일(`.shp`, `.shx`, `.dbf`, `.prj`)과 CRS를 확인한다.
4. 필드 스키마 변화, 고유번호 중복, 빈 도형, 잘못된 도형을 검사한다.
5. 스테이징 테이블에 적재한 뒤 이전 스냅샷과 추가·삭제·경계·분류 변화를 계산한다.
6. 품질 임계값을 통과하면 현재 버전을 전환하고, 이전 버전은 삭제하지 않는다.

원본 데이터 제공 페이지의 직접 다운로드 URL은 바뀔 수 있다. 페이지 내부 URL을 스크레이핑해 무인 다운로드하기보다는 공식적으로 제공되는 고정 연계 방법을 문의하거나, 승인된 관리자가 파일을 등록하고 이후 적재·검증만 자동화하는 방식을 사용한다.

### 6.2 실시간 조회

- 지도 이동마다 공공 OpenAPI를 호출하지 않는다.
- 내부 DB를 기본 조회원으로 사용하고 외부 API는 팜맵 ID/PNU 보완 조회에 한정한다.
- 외부 응답에는 조회 시각, API 종류, 요청 좌표계, 원문 식별값을 함께 저장한다.
- 타임아웃, 지수 백오프, 호출량 계측, 회로 차단기와 캐시를 둔다.
- WMS 장애 시 내부 SHP 도형만으로 조사 업무가 계속되도록 한다.

### 6.3 보안

- 농지대장, 소유자, 연락처, 등기 및 현장 증거는 공개 팜맵 데이터와 다른 보호등급으로 관리한다.
- 역할 기반 접근제어, 기관별 데이터 범위, 조회·내보내기 감사로그를 적용한다.
- 공공데이터포털 서비스키는 서버에만 저장하고 브라우저 번들·로그·URL 분석도구에 노출하지 않는다.
- `VITE_` 변수는 Vite 빌드 결과에서 공개된다. 도메인 등록형 WMS 키 외의 비밀값을 `VITE_` 변수로 두지 않는다.

## 7. 환경변수

### 7.1 현재 프런트엔드가 사용하는 변수

현재 `src/lib/farmMap.ts`가 읽는 변수다. `.env.local`에 실제 값을 넣고 저장소에는 커밋하지 않는다.

```dotenv
# 팜맵 사이트에서 발급받은 도메인 등록형 키
VITE_FARMMAP_API_KEY=

# 키 발급 시 등록한 정확한 origin. 개발 포트도 포함한다.
VITE_FARMMAP_DOMAIN=http://localhost:5173

# 화면에 사용할 팜맵 데이터 기준연도
VITE_FARMMAP_YEAR=2025
```

주의사항:

- 코드의 기본 도메인은 `window.location.origin`이지만, 운영에서는 신청한 도메인을 명시하는 편이 안전하다.
- 개발·스테이징·운영 origin이 다르면 각각 등록한다. 팜맵 화면은 최대 3개 키 발급을 안내한다.
- `VITE_FARMMAP_API_KEY`는 브라우저에서 확인할 수 있다. 이 키를 일반 비밀키로 취급해 권한을 확대하지 말고 등록 도메인과 최소 권한만 사용한다.
- 공공데이터포털의 `serviceKey`를 `VITE_FARMMAP_API_KEY`에 넣지 않는다. 두 키는 발급처와 용도가 다르다.

### 7.2 서버 연동 시 권장 변수

아래 변수는 현재 프런트엔드에서 읽지 않으며, 백엔드·적재 작업을 추가할 때 사용하는 권장 이름이다.

```dotenv
# 서버 전용: 공공데이터포털 프로젝트 서비스키
DATA_GO_KR_SERVICE_KEY=

DATA_GO_KR_FARMMAP_BASE_URL=https://apis.data.go.kr/B552895/getFarmmapService

# 팜맵 원본 및 표시 설정
FARMMAP_SOURCE_CRS=EPSG:5179
FARMMAP_WMS_ENDPOINT=https://agis.epis.or.kr/ASD/farmmapApi/wms.do
FARMMAP_WMS_LAYER=farm_map_api
FARMMAP_SYNC_YEAR=2025

# 배치 원본 보관 위치와 공간 DB 연결정보는 배포 환경에 맞게 지정
FARMMAP_RAW_DATA_DIR=
DATABASE_URL=
```

`DATA_GO_KR_SERVICE_KEY`와 `DATABASE_URL`은 비밀 저장소에서 주입하고 클라이언트에 전달하지 않는다. 연도는 코드 기본값에만 의존하지 말고 실제 적재가 완료된 활성 스냅샷에서 읽는 것이 좋다.

## 8. 신청 절차

### 8.1 팜맵 사이트 키와 WMS

1. [농식품 팜맵 서비스](https://agis.epis.or.kr/ASD/main/intro.do)에서 이메일 인증 후 회원가입한다.
2. 공공기관 업무라면 공공 가입유형과 필요한 권한을 신청한다. 권한별 사용 메뉴가 다르다.
3. `OPEN API`의 인증키 관리에서 기관·부서·전화번호, 공공/민간 활용 분야, 웹/모바일/연구·분석 유형, 서비스명, 운영 상태, 도메인, 서비스 설명을 입력한다.
4. 개발·스테이징·운영에서 실제 사용할 origin을 정확히 등록한다.
5. 발급 키로 WMS GetCapabilities를 호출해 레이어와 지원 CRS를 검증한다.
6. 호출량, WFS, 대량 이용 또는 외부 제공 범위가 불명확하면 시스템 문의처 `031-778-7728`, `agis@epis.or.kr`에 서면 확인한다.

팜맵 FAQ는 현재 자체 API 호출 건수 제한이 없다고 설명하면서도 이용현황에 따라 제한이 생길 수 있다고 고지한다. 무제한을 서비스 수준 보장으로 해석하지 말고 모니터링과 캐시를 적용한다.

### 8.2 공공데이터포털 OpenAPI

1. [공공데이터포털](https://www.data.go.kr/)에 가입한다.
2. [팜 맵 조회 서비스](https://www.data.go.kr/data/15057368/openapi.do)에서 활용신청한다.
3. 개발 또는 운영 프로젝트와 키를 발급받는다.
4. 개발 키로 좌표·반경 조회와 페이지네이션, 오류코드, 인코딩을 검증한다.
5. 운영 호출량이 기본 트래픽을 넘으면 활용사례와 예상량을 등록해 증설을 신청한다.
6. 서버 비밀 저장소에 키를 등록하고 호출량·오류율·응답시간 경보를 설정한다.

### 8.3 SHP

1. 필요한 모든 광역시도의 데이터 상세 페이지를 식별한다.
2. 각 페이지에서 기준일, 갱신주기, 유의사항과 이용허락 범위를 확인한다.
3. 공식 다운로드 파일과 메타데이터를 함께 보관한다.
4. 적재 품질검사 후 활성 스냅샷으로 승격한다.
5. 연 1회 정기 점검 외에도 제공 페이지 수정일과 팜맵 공지를 확인한다.

## 9. 운영 전 점검표

- [ ] 팜맵 사이트 키와 공공데이터포털 키를 구분했다.
- [ ] 개발·스테이징·운영 도메인을 실제 origin과 동일하게 등록했다.
- [ ] WMS GetCapabilities로 레이어명, CRS, 버전과 이미지 형식을 확인했다.
- [ ] WFS를 사용한다면 운영기관의 최신 명세 또는 서면 답변을 확보했다.
- [ ] 모든 지역 SHP의 기준연도, 체크섬, 출처 URL과 라이선스를 보존했다.
- [ ] EPSG:5179 원본 도형을 유지하고 웹 변환 결과를 표본 검증했다.
- [ ] PNU 1:1 조인을 가정하지 않고 중첩률 및 불일치 상태를 저장한다.
- [ ] 자동 분석 결과를 법적 확정 판정과 분리했다.
- [ ] 외부 API 장애·제한 시 내부 SHP만으로 핵심 조사가 가능하다.
- [ ] 웹사이트·타일·비공개 API 크롤링이 없다.
- [ ] 항공영상과 외부 배경지도의 별도 이용조건을 확인했다.
- [ ] 출처표시, 데이터 버전 및 판정 감사로그가 결과물에 포함된다.
- [ ] 소유자·경작자·현장 증거에 역할 기반 접근제어와 내보내기 로그를 적용했다.
